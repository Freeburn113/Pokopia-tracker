# Pokopia-tracker



A lightweight, open-source Pokémon tracker built to help you keep tabs on your collection with ease. 



Built with **Vue 3**, **Tailwind CSS**, and modern web standards.



## Features

* **Search & Track:** Quickly find and manage your Pokémon.

* **Responsive UI:** Fully styled with Tailwind for a clean look on desktop and mobile.



## Tech Stack

* **Framework:** [Vue.js 3](https://vuejs.org/)

* **Styling:** [Tailwind CSS](https://tailwindcss.com/)

* **Data Source Images:** [PokeAPI](https://pokeapi.co/)
